# Sandbox inventory

Every artifact created in the sandbox, so it can be cleaned up:
- PRs 1–9, their branches and threads;
- UI-test writes on PR 7: threads 31–40, votes and their resets;
- the owner's own comments on PR 9.

**Every sandbox write must be added here.**
